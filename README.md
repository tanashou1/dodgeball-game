# 放課後ドッジ！

子供向けの日本語ドッジボールゲーム。ブラウザだけで動く、静的なHTML/CSS/JavaScript製です。

- 3対3、2分間の試合。相手を全員アウトにするか、時間終了時に多く残れば勝利。
- 矢印 / WASD：移動
- スペース長押し → 離す：投球（長押しでパワーアップ）
- C：タイミングよくキャッチ
- 相手をクリック / タップ：ねらう相手を変更。Qキーでも切り替え。
- Escape：休けい
- スマートフォン：画面下の操作ボタン

ノーバウンドのボールに当たるとアウト。キャッチの受付時間と相手の投球速度は難易度で変わります。自分がアウトになったら、残った仲間に操作が移ります。ボールがコートを出た場合や転がった場合は相手側に渡り、すぐ試合が続きます。外野や復活ルールはありません。

## GitHub Pages

このディレクトリのファイルをリポジトリの `main` ブランチ直下に置き、Settings → Pages → Deploy from a branch → `main` / `(root)` → Save を選択してください。ビルド不要です。

ローカルでは `python3 -m http.server 8080` を実行してブラウザで開けます。

個人情報の収集やサーバーへのスコア送信はありません。フォントが読み込めない環境では端末の標準フォントで表示します。
